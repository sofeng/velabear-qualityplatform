TOOLBOX

六类工具箱能力，按需挂载

能力不是越多越好 —— 按当前任务选择必要能力，避免上下文过载。

Prompt 提示词

固定格式的分析、总结、审查、生成任务，如需求分析、用例生成。

Skill 技能

带规则、步骤与输出合约的专业能力，如缺陷分析、各阶段官方研发技能。

Agent 智能体

需要决策、检查与串联多步动作的能力，如 Playwright 测试 Agent。

Flow 流程

固定流程编排，如 AI 研发闭环、AI 自动部署等长链路。

MCP 上下文

让 AI 安全读取外部或平台上下文，如只读接入需求、任务、缺陷、部署。

Tool 工具

执行具体动作，如平台查询、需求创建、开发任务执行、部署执行。

## 🔧 故障排除

### 问题1: Django启动失败

**症状**: 运行 `python manage.py runserver` 报错

**排查**:
```bash
# 检查配置
python manage.py check

# 查看迁移状态
python manage.py showmigrations

# 测试数据库连接
python manage.py dbshell
```

### 问题2: 前端页面空白或报错

**解决方案**:
```bash
# 清除缓存并重新构建
cd frontend
rm -rf node_modules/.vite
npm run build

# 或使用开发服务器
npm run dev
```

### 问题3: 新字段不显示

**检查清单**:
- [ ] 数据库迁移已应用: `python manage.py migrate ai_development`
- [ ] 前端已重新构建: `npm run build`
- [ ] 浏览器缓存已清除: Ctrl+Shift+R
- [ ] 测试的是新创建的任务（不是旧任务）

### 问题4: Celery任务不执行

**检查**:
```bash
# 确认Celery Worker运行
tasklist | findstr celery

# 查看Celery日志
# 在Celery Worker终端查看输出

# 检查消息队列
# 确认Redis/RabbitMQ正在运行
```

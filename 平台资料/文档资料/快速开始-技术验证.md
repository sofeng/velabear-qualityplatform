# 快速开始 - 技术验证

## 🎯 目标

验证AI自动编码的核心技术可行性：
1. ✅ Anthropic API是否可用
2. ✅ AI能否生成高质量代码
3. ✅ 代码解析是否准确
4. ✅ Docker容器文件操作是否正常

## 📋 前置条件

### 1. 安装依赖

```bash
pip install anthropic docker
```

### 2. 获取Anthropic API Key

访问 https://console.anthropic.com/ 获取API Key

### 3. 设置环境变量

**Windows (CMD)**:
```cmd
set ANTHROPIC_API_KEY=sk-ant-api03-your-key-here
```

**Windows (PowerShell)**:
```powershell
$env:ANTHROPIC_API_KEY="sk-ant-api03-your-key-here"
```

**Linux/Mac**:
```bash
export ANTHROPIC_API_KEY=sk-ant-api03-your-key-here
```

### 4. 确保Docker正在运行

```bash
docker --version
docker ps
```

## 🔧 如何调整

### 改进Prompt

编辑 `apps/ai_development/ai_tools/anthropic_api_controller.py` 中的 `_generate_development_prompt` 方法。

建议调整点:
- 更明确的输出格式要求
- 增加代码规范说明
- 添加具体的技术栈说明
- 要求生成更详细的注释

### 改进解析规则

编辑 `apps/ai_development/utils/code_parser.py`，调整正则表达式以适应AI实际输出格式。

### 切换模型

在配置中可以选择:
- `sonnet` - 平衡性能和成本(推荐)
- `opus` - 最高质量,但成本较高
- `haiku` - 最快速度,成本最低

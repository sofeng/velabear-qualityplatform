# 流程引擎开发前版本备份说明

## 目的

本次提交用于冻结当前平台状态，作为“流程引擎开发前”的基线版本。

后续如果在流程引擎第一期、第二期、第三期开发过程中出现以下情况，可以直接回滚到该版本：

- 流程引擎接入导致核心业务不可用
- 需求流转或缺陷流转出现严重回归
- 测试验证无法达到可用性、易用性、好用性的最低要求
- 需要重新评估流程引擎技术路线

## 备份标识

- 备份类型：Git 基线提交 + Git Tag
- 基线分支：`main`
- 基线说明：`流程引擎开发前版本`
- 预期提交信息：`chore: 备份流程引擎开发前版本基线`
- 预期标签：`pre-workflow-engine-20260421`

## 回滚方式

查看基线提交：

```bash
git show pre-workflow-engine-20260421 --stat
```

临时切换到基线版本排查问题：

```bash
git checkout pre-workflow-engine-20260421
```

如果需要在当前分支强制回退到该基线：

```bash
git reset --hard pre-workflow-engine-20260421
```

## 使用要求

- 流程引擎相关开发必须以该基线为起点继续推进
- 每完成一个阶段都要进行可用性、易用性、好用性验证
- 若验证不通过，优先修复；无法修复时，应停止继续开发，并明确说明阻断原因

## 已知例外

以下文件名在 Windows 环境中属于保留名，Git 无法正常索引，因此不纳入本次基线提交：

- `nul`
- `frontend/nul`
- `frontend/src/views/manual-testcases/nul`

除上述保留名文件外，其余当前工作区内容均应纳入本次基线备份。

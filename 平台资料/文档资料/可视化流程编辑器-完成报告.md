## 🎯 项目目标

开发一个基于Playwright快照文件的可视化测试用例编辑器，允许测试人员通过拖拽流程图的方式创建UI自动化测试，无需编写代码。

### 核心功能要求

1. ✅ **页面节点内部元素渲染** - 在页面节点内直接显示可交互元素
2. ✅ **元素间连线和执行路径** - 通过连接元素定义测试步骤
3. ✅ **Playwright脚本生成** - 基于流程图自动生成Python代码
4. ✅ **测试脚本执行** - 在平台内直接执行生成的测试脚本

## 🔧 技术实现亮点

### 1. 创新的可视化设计

**传统方式**:
```python
# 手写Playwright代码
await page.fill('#username', 'admin')
await page.fill('#password', 'password123')
await page.click('button:has-text("登录")')
```

**现在的方式**:
1. 拖拽页面节点到画布
2. 加载Playwright快照
3. 在节点内连接元素
4. 点击"生成脚本"
5. 一键执行测试

**优势**:
- ✅ 零编码，降低测试门槛
- ✅ 可视化流程，易于理解和维护
- ✅ 基于真实快照，保证准确性
- ✅ 自动生成代码，可导出复用

### 2. 智能选择器系统

系统为每个元素自动生成多个选择器，按优先级排序：

```javascript
// 优先级1: data-ref选择器（最稳定）
[data-ref="username"]

// 优先级2: 文本选择器（直观）
button:has-text("登录")

// 优先级3: role选择器（语义化）
[role="button"]

// 优先级4: tag选择器（通用）
button
```

脚本生成时自动选择最佳选择器，提高测试稳定性。

### 3. 拓扑排序保证执行顺序

使用BFS拓扑排序算法确定节点执行顺序：

```
输入流程图: A → B → D
              ↓
              C → D

拓扑排序结果: [A, B, C, D] 或 [A, C, B, D]
```

保证：
- ✅ 前置节点一定在后续节点之前执行
- ✅ 检测循环依赖并警告
- ✅ 并行路径可以按任意顺序（但都满足依赖）

### 4. 安全的脚本执行机制

**安全措施**:
1. ✅ **认证保护**: 只有登录用户可执行
2. ✅ **超时限制**: 5分钟超时，防止无限执行
3. ✅ **资源清理**: 自动清理临时文件
4. ✅ **路径遍历防护**: 防止读取系统敏感文件
5. ✅ **沙箱隔离**: 使用临时目录执行

**执行流程**:
```
1. 验证用户身份
2. 生成唯一脚本ID
3. 写入临时目录
4. subprocess执行（带超时）
5. 捕获stdout/stderr
6. 清理临时文件
7. 返回执行结果
```

### 5. 高性能快照解析

**优化策略**:
1. **前端缓存**: 已加载的快照文件缓存在内存
2. **懒加载**: 只加载用户选择的快照
3. **元素限制**: 页面节点最多显示10个元素（避免UI过载）
4. **异步加载**: 使用ElLoading提供加载反馈

### 6. 响应式UI设计

**布局结构**:
```
+------------------+------------------+------------------+
|   工具栏         |     画布         |   配置面板       |
|   - 节点拖拽     |   - 流程图编辑   |   - 节点配置     |
|   - 保存加载     |   - 连线操作     |   - 快照选择     |
|   - 生成执行     |   - 缩放平移     |   - 执行路径     |
+------------------+------------------+------------------+
```

**交互优化**:
- ✅ 拖拽式节点创建
- ✅ 右键菜单快捷操作
- ✅ 实时配置预览
- ✅ 双击节点编辑

## 🎓 使用示例

### 场景: 创建登录测试流程

#### 步骤 1: 创建流程图结构
```
[开始节点] → [登录页节点] → [等待节点] → [首页节点] → [结束节点]
```

#### 步骤 2: 配置开始节点
- 浏览器: chromium
- URL: https://example.com/login
- 视口: 1920x1080

#### 步骤 3: 配置登录页节点
- 加载快照: login-page.yml
- 定义执行路径:
  1. 用户名输入框 → 密码输入框 (fill: "admin")
  2. 密码输入框 → 登录按钮 (fill: "password123")
  3. 登录按钮 → (点击)

#### 步骤 4: 配置等待节点
- 操作类型: sleep
- 等待时间: 2000ms

#### 步骤 5: 配置首页节点
- 加载快照: home-page.yml
- 验证登录成功（悬停用户头像）

#### 步骤 6: 生成并执行
- 点击"生成脚本"查看代码
- 点击"执行测试"运行测试
- 查看执行结果

**生成的脚本**:
```python
"""
自动生成的Playwright测试脚本
生成时间: 2026-04-14 10:30:00
"""

import asyncio
from playwright.async_api import async_playwright

async def run_test():
    async with async_playwright() as p:
        # 启动浏览器
        browser = await p.chromium.launch(headless=False)
        context = await browser.new_context(
            viewport={'width': 1920, 'height': 1080}
        )
        page = await context.new_page()

        # 访问页面
        await page.goto('https://example.com/login')
        await page.wait_for_load_state('networkidle')

        # 页面: 登录页
        await page.fill('[data-ref="username"]', 'admin')
        await page.fill('[data-ref="password"]', 'password123')
        await page.click('button:has-text("登录")')

        # 等待
        await page.wait_for_timeout(2000)

        # 页面: 首页
        await page.hover('img[alt="用户头像"]')

        # 测试完成
        print("测试执行完成")

        # 关闭浏览器
        await browser.close()

if __name__ == "__main__":
    asyncio.run(run_test())
```

A:
1. 确认Playwright已正确安装
2. 检查URL是否可访问
3. 验证选择器是否正确

A: 可以。在开始节点配置移动端视口大小即可。

## 📊 数据结构

### 脑图数据格式（JSON）- 专业版完整结构

```json
{
  "root": {
    "data": {
      "text": "手工用例测试",
      "nodeType": "module"
    },
    "children": [
      {
        "data": {
          "text": "登录功能",
          "nodeType": "module"
        },
        "children": [
          {
            "data": {
              "text": "正常登录测试",
              "nodeType": "case",
              "priority": 0,
              "status": "not_run",
              "tags": ["正向", "核心", "冒烟"],
              "caseId": "TC-LOGIN-001",
              "preCondition": "用户已注册且账号状态正常",
              "steps": "1. 打开登录页面\n2. 输入正确的用户名和密码\n3. 点击登录按钮",
              "expect": "登录成功，跳转到首页",
              "remark": "核心功能，必须通过"
            }
          },
          {
            "data": {
              "text": "密码错误测试",
              "nodeType": "case",
              "priority": 1,
              "status": "not_run",
              "tags": ["负向"],
              "caseId": "TC-LOGIN-002",
              "preCondition": "用户已注册",
              "steps": "1. 打开登录页面\n2. 输入正确的用户名\n3. 输入错误的密码\n4. 点击登录按钮",
              "expect": "提示'用户名或密码错误'",
              "remark": ""
            }
          }
        ]
      }
    ]
  }
}
```

**数据层级**:
1. 根节点 - 用例脑图标题
2. 功能模块 - 一级子节点（nodeType: module）
3. 测试场景/用例 - 多级子节点（nodeType: case/requirement）

**完整字段说明**：
- `text` - 节点文本（必填）
- `nodeType` - 节点类型：module/case/requirement
- `priority` - 优先级：0(P0)/1(P1)/2(P2)/3(P3)
- `status` - 用例状态：not_run/pass/fail/block
- `tags` - 标签数组：["正向", "接口", "冒烟"]
- `caseId` - 用例编号：TC-XXX-001
- `preCondition` - 前置条件
- `steps` - 测试步骤（支持多行）
- `expect` - 期望结果
- `remark` - 备注说明

## 🔧 使用指南

### 基础操作

#### 步骤1: 访问手工用例模块

**方式1 - 从首页**:
1. 访问 http://localhost:3000
2. 点击"手工用例"卡片
3. 在新标签页打开手工用例列表

**方式2 - 从菜单**:
1. 在任意页面点击左侧菜单切换
2. 选择"手工用例"模块
3. 看到3个菜单项

#### 步骤2: 创建用例脑图

1. 点击列表页的"创建用例脑图"按钮
2. 填写用例名称和描述
3. 点击"确定"
4. 自动跳转到脑图编辑器

#### 步骤3: 编辑脑图

1. 在编辑器中设计测试用例结构
2. 使用鼠标添加、删除、移动节点
3. 输入节点文本内容
4. 点击"保存"按钮保存数据

#### 步骤4: 导出用例

1. 点击"导出"按钮
2. 自动下载JSON文件
3. 文件名格式：`手工用例脑图_时间戳.json`

#### 步骤5: 导入用例

1. 点击"导入"按钮
2. 选择之前导出的JSON文件
3. 自动加载脑图数据

1. 选中用例节点
2. 查看右侧详情面板
3. 填写以下字段：
   - **用例ID**：建议格式 TC-模块-序号（如TC-LOGIN-001）
   - **前置条件**：执行用例前需要满足的条件
   - **测试步骤**：详细的操作步骤（支持多行）
   - **期望结果**：预期的测试结果
   - **备注**：补充说明信息

#### 6. 使用过滤功能
**打开过滤对话框**：
- 点击工具栏"过滤"按钮

**设置过滤条件**：
- **按优先级**：勾选要显示的优先级（可多选）
- **按状态**：勾选要显示的状态（可多选）
- **按标签**：输入标签关键字（模糊匹配）

**应用过滤**：
- 点击"应用过滤"按钮
- 不符合条件的节点会被隐藏

**清除过滤**：
- 点击工具栏"清除过滤"按钮
- 所有节点重新显示

#### 7. 使用详情面板
- **显示/隐藏**：点击工具栏"显示/隐藏详情"按钮
- **面板功能**：
  - 实时显示选中节点的所有属性
  - 表单式编辑所有扩展字段
  - 可视化管理标签
  - 失去焦点自动保存

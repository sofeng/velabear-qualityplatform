========================================
  服务管理
========================================

停止前端服务:
  找到运行 npm run dev 的窗口，按 Ctrl+C

停止后端服务:
  找到运行 python manage.py runserver 的窗口，按 Ctrl+C

停止Celery:
  taskkill /F /IM celery.exe

========================================
  故障排查
========================================

如果登录后出现错误:
1. 检查浏览器控制台 (F12)
2. 查看Django日志输出
3. 确认数据库连接正常
4. 检查用户权限

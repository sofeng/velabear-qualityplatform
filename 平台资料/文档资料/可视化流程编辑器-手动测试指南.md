## 测试场景 1: 快照加载和解析测试

### 目标
验证快照文件能否正确加载、解析并渲染可交互元素。

### 测试步骤

#### 步骤 1: 创建基础流程
1. 从左侧工具栏拖拽 **"开始"** 节点到画布中央
2. 点击开始节点，在右侧配置面板设置：
   - 浏览器类型: `chromium`
   - 初始URL: `http://localhost:3002` (或任意URL)
   - 视口宽度: `1920`
   - 视口高度: `1080`
   - Headless模式: **不勾选** (这样可以看到浏览器)

#### 步骤 2: 添加页面节点并加载快照
1. 从工具栏拖拽 **"页面"** 节点到画布
2. 从开始节点的右侧连接点拖拽连线到页面节点的左侧连接点
3. 点击页面节点，在右侧配置面板：
   - **页面名称**: 输入 `主页面`
   - **快照文件**: 从下拉列表选择 `page-2026-04-10T01-39-03-267Z.yml`
4. 点击 **"加载快照"** 按钮

#### 预期结果
✅ **成功标志**:
- 显示提示消息: "快照加载成功，共解析 XX 个可交互元素"
- 页面节点内部显示元素列表，包括：
  - "返回门户" (generic + cursor=pointer)
  - "汪芜" (button)
  - "服务台" (generic + cursor=pointer)
  - "数据仓" (generic + cursor=pointer)
  - "基础档案" (generic + cursor=pointer)
  - "收费管理" (generic + cursor=pointer)
  - 等等...（最多显示10个）
- 每个元素右侧显示 **黄色连接点**
- 右侧配置面板的"元素树"显示完整的层级结构

#### 验证点
- [ ] 快照文件下拉列表能正常加载（显示15个文件）
- [ ] 点击"加载快照"后有加载动画
- [ ] 加载成功显示成功提示
- [ ] 页面节点内部元素列表正确显示
- [ ] 元素类型徽章显示正确（button、generic等）
- [ ] 元素文本显示正确（截断长文本）
- [ ] 黄色连接点显示在每个元素右侧
- [ ] 右侧元素树显示完整层级

#### 预期结果

2. 再创建连线: "基础档案" → "收费管理"

#### 预期结果
✅ **成功标志**:
- 弹出脚本预览对话框
- 显示生成的Python代码
- 代码结构完整，包含：
  ```python
  """
  自动生成的Playwright测试脚本
  生成时间: YYYY-MM-DD HH:mm:ss
  """

  import asyncio
  from playwright.async_api import async_playwright

  async def run_test():
      async with async_playwright() as p:
          # 启动浏览器
          browser = await p.chromium.launch(headless=False)
          context = await browser.new_context(
              viewport={'width': 1920, 'height': 1080}
          )
          page = await context.new_page()

          # 访问页面
          await page.goto('http://localhost:3002')
          await page.wait_for_load_state('networkidle')

          # 页面: 主页面
          await page.click('[data-ref="e928"]')  # 服务台
          await page.click('[data-ref="e934"]')  # 数据仓

          # 等待
          await page.wait_for_timeout(2000)

          # 页面: 第二页
          # (如果有执行路径，会生成对应代码)

          # 测试完成
          # 生成测试报告
          print("测试执行完成")

          # 关闭浏览器
          await browser.close()

  if __name__ == "__main__":
      asyncio.run(run_test())
  ```

## 测试场景 5: 脚本执行测试

### 目标
验证能否在平台内直接执行生成的Playwright脚本。

### 前置条件
**确保Playwright已安装**:
```bash
pip install playwright
python -m playwright install chromium
```

### 测试步骤

#### 步骤 1: 执行脚本
1. 在脚本预览对话框中，点击 **"执行测试"** 按钮
2. 观察加载动画: "正在执行测试脚本..."
3. 等待执行完成（注意：由于URL是localhost:3002，可能会打开浏览器访问前端页面）

#### 预期结果

**情况A: 执行成功**
✅ **成功标志**:
- 显示成功提示: "脚本执行成功"
- 弹出执行结果对话框
- 显示标准输出（stdout）:
  ```
  测试执行完成
  ```
- 如有Playwright日志，也会显示

**情况B: 执行失败（预期情况，因为URL可能不是真实测试环境）**
❌ **失败标志**:
- 显示错误提示: "脚本执行失败"
- 弹出执行结果对话框
- 显示错误输出（stderr）:
  ```
  playwright._impl._errors.TimeoutError: Timeout 30000ms exceeded.
  或
  playwright._impl._errors.Error: page.click: Target closed
  ```

**这是正常的！** 因为：
1. URL设置的是`http://localhost:3002`（前端页面）
2. 快照文件来自其他系统，元素选择器在前端页面上不存在
3. 这个测试的目的是验证**脚本执行机制**，不是验证脚本逻辑

#### 步骤 2: 验证执行机制
无论成功还是失败，检查：
- [ ] 有加载动画提示

- [ ] 能捕获stdout输出
- [ ] 能捕获stderr错误
- [ ] 结果对话框显示详细信息
- [ ] 执行完成后可关闭对话框
